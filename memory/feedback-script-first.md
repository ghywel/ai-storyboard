Before any scene code: the idea in one paragraph, why this take, tone rules, palette and type, the lyric presentation,
camera and compositor grammar, motifs, the set and cast, the plates table, and the script (per line: picture, face and
pose, clue, hit). Commit it.

**Why:** a design on disk survives a crash, a usage limit or a new session; parallel authors need one source of truth;
the director can read it.

**How to apply:** use templates/TREATMENT.md. For several takes, write VARIANTS.md (one concept per take and a
no-match table) before either treatment. See [[feedback-variants-no-match]].
