# Memory index

Working rules for code-drawn music videos with a human director, in Claude Code memory format (one fact per file).
Copy the files into a project's memory directory and keep this index in its MEMORY.md.

- [Storyboard gate](feedback-storyboard-gate.md): review at storyboard depth before polish and before the final
- [Script first](feedback-script-first.md): treatment and shot-by-shot script written and committed before building
- [Measure the take](feedback-measure-the-take.md): master WAV, forced alignment, drum-decided beats; generator timings are drafts
- [Environments and clues](feedback-environments-and-clues.md): real places, a named clue per shot, paid off later
- [One face acts](feedback-one-face-acts.md): anime acting, faces follow words, chibi pops, lines of force
- [Silhouettes emote](feedback-silhouettes-emote.md): faceless people with body language and one accessory each
- [Lyric readable](feedback-lyric-readable.md): per word, never ahead, never covered, inside the concept
- [Compositor restraint](feedback-compositor-restraint.md): capped shakes on real hits; the silent beat gets nothing
- [Variants, no match](feedback-variants-no-match.md): one concept per take, a no-match table first
- [Orchestration](feedback-orchestration.md): frozen kit, one owner per shared decision, review and commit as plates land
- [Render memory](feedback-render-memory.md): encode in the page, guarded resumable segments
- [Verify before delivery](feedback-verify-before-delivery.md): decode, frame count, joins, credits
- [Knowns must be proven](feedback-knowns-must-be-proven.md): a fact needs its proof, with scope
- [Silent failure](feedback-silent-failure.md): assert every data step returned enough
- [Assert every patch](feedback-assert-every-patch.md): replace only on an exact single match
- [Best tool, not nearest](feedback-best-tool-not-nearest.md): compare options before building
- [Credits and privacy](feedback-credits-and-privacy.md): credit as asked; no unknown-rights material; sweep before publishing
- [Estimates](feedback-estimates.md): measure a slice, then multiply
- [Project template](project-film-template.md): the per-film project memory to keep current
