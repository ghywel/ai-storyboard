Before reaching for the nearest tool, ask what would do the job best and what each option costs.

**Why:** the generator's timed lyrics were at hand and wrong; an image-generation key was at hand and unnecessary,
because the reference look was all code.

**How to apply:** name the alternatives in one line each, measure the cheapest discriminating difference, then choose.
