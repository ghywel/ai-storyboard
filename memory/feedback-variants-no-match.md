description: "Several takes become several films: measure each take, give each one concept, and write a no-match table before building"
metadata:
  type: feedback
---

Measure each take's shape (intro brightness, dips, repeats, peak loudness, loud or hushed outro), choose the concept
that suits it, and stage every line in each film side by side in a table so no picture is shared. Share the tools,
the character and the direction; never the pictures.

**Why:** the director asked for variety between takes "whilst faithfully retelling their story"; a table written first
is the only reliable way to keep two parallel builds apart.

**How to apply:** VARIANTS.md before either treatment; brief each film's authors with the other film's pictures as a
do-not-borrow list.
